## AaaS 与 MaaS / PaaS 边界

AaaS 要求服务方托管或管理 Agent 的执行、异步任务、环境、生命周期、编排、可观测性或企业访问。单纯模型/API 是 MaaS；只有算力或通用容器而没有 Agent 生命周期证据时是 PaaS。Cline、Pi、DSH、OpenCode、Aider、Continue 与 Roo Code 的本地 CLI、IDE 或普通 release 不进入本页；本轮未发现它们新增云端托管证据。
