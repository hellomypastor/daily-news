## 今日概览

采集窗口：**2026-11-10 10:49 至 2026-11-11 10:49（Asia/Shanghai）**。本轮没有具备精确时分的第一方 AaaS 发布；Google Agent Runtime 与 Adobe 托管 Agent 动态只有日期或时区不完整，按证据状态保留。

## 顶部动态与远程 / 云端执行

- Google Gemini Enterprise Agent Platform 的[官方 release notes](https://docs.cloud.google.com/gemini-enterprise-agent-platform/release-notes)标注 11 月 10 日：控制台新增独立 Memory Bank 页面，并更新已部署 Agent Runtime 的记忆控制。符合托管运行时与生命周期控制面定义，但无具体时分。
- Adobe [官方公告](https://news.adobe.com/news/2026/11/adobe-powers-new-era-of-creativity)扩展 Creative Agent 与 GenStudio 中的 CX Enterprise Coworker；托管应用内 Agent 符合 AaaS，公告同时提到的本地 MCP 集成本身不单独算 AaaS。

## 海外厂商

Cognition Devin 已检查托管异步执行、环境、并发、定价、企业接入与集成，窗口内无新增。xAI/Grok 已检查 News、Bot/Build changelog、Bot docs 与 API release notes；普通模型/API/工具调用不满足托管生命周期定义，本轮无新增。Microsoft、AWS、Replit、Cursor、Lindy、CrewAI、LangGraph、GitHub、Cloudflare、Factory 与 Sourcegraph/Amp 也未发现需新增的窗口内发布。

## 中国市场

ByteDance、Alibaba、Tencent、Baidu、Zhipu、Kimi、MiniMax 等入口已检查。千问办公与腾讯元器候选因只有二手来源且事件位于窗口外，保留在观察池。

## 日期未确认

Google 与 Adobe 两项官方动态仅能确认到日期或页面所列时间缺少明确时区，因此不宣称严格落入 24 小时。Google 的 [Gemini 4 Carbon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)是 MaaS/模型与 Agent 能力邻近信号，不因支持长时工作流就误写成托管 Agent 服务。

## AaaS 与 MaaS/PaaS 边界

Cline Cloud 已有托管沙箱等旧能力，但本轮无新增；Pi、DSH、OpenCode、Aider、Continue、Roo Code 的本地、headless、background 或自托管远程能力不等于服务商托管执行。普通 Grok API、Gemini Carbon 与本地 MCP 仅作邻近信号。

## 采集状态

Devin 与 xAI/Grok 强制渠道、海外/中国平台和七个 harness 均已检查。初始候选 8 条，保留 5 个唯一来源；二次补搜：否。失败与原文缺失已记录。
