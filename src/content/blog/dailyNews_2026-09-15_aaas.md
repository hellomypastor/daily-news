## 今日概览

截至 2026-09-15 10:46（Asia/Shanghai），过去 24 小时确认两条符合 AaaS 定义的企业 Agent 动态：Salesforce 扩展 Agentforce 的长期运行与可审计执行能力；FutureVault 发布面向受监管文档流程的托管 Agent。两者都不仅是模型 API，而是覆盖执行生命周期、权限、治理或跨系统编排的服务。

## 重点动态

### Salesforce 扩展 Agentforce 的长周期执行能力

Salesforce 于 9 月 14 日发布一组面向高价值业务流程的 Agentforce Agents。官方说明其平台以记忆、durable execution 与 dynamic steering 支持跨天/跨周目标，并提供动作审计记录；首个长周期运行时 Agent 为 Hunter，后续计划允许客户构建自己的长周期 Agent。这是从一次性对话走向托管执行生命周期的明确信号：[官方发布](https://www.salesforce.com/ap/news/press-releases/2026/09/14/ph-salesforce-expands-agentforce-with-a-new-portfolio-of-ai-agents-built-for-high-value-work/)。

### FutureVault 将 Agent 放入受监管文档工作流

FutureVault 于 9 月 14 日宣布 AI Agents，可在金融服务等场景中跨现有系统执行多步骤文档流程，并沿用既有权限结构、对异常和缺失文档升级给人工复核。其核心证据是托管的端到端执行、治理和人工审批机制，而非单纯模型调用：[官方新闻稿](https://www.prnewswire.com/news-releases/futurevault-launches-ai-agents-bringing-governed-end-to-end-workflow-execution-to-the-document-layer-302877663.html)。

## 远程 / 云端 Agent 执行

| 平台 | 能力信号 | AaaS 判断 |
|---|---|---|
| Salesforce Agentforce | 记忆、长周期运行时、动态引导、跨系统流程与审计记录 | 符合：平台托管执行生命周期和企业控制面 |
| FutureVault AI Agents | 多步骤文档流程、既有权限、异常升级与人工复核 | 符合：在受监管环境中托管跨系统执行 |

## 海外厂商

- **Cognition Devin**：已显式检查官方产品新闻、变更日志与文档中的异步执行、环境、并发、定价、企业接入和集成，本轮无新增。
- **xAI / Grok**：已显式检查 Grok Bot 官方新闻、指南和 API 文档中的托管 Agent、异步任务、云端电脑、工具及远程执行，本轮无 24–72 小时新增；普通模型/API 动态不纳入 AaaS。
- Anthropic、OpenAI、Google、Microsoft、Replit、Cursor、Lindy、CrewAI、LangGraph Platform、Cloudflare、Factory、Sourcegraph/Amp：本轮未发现窗口内可核实新增。Claude / OpenAI 既有托管能力详见对应专题页，本页不重复旧背景。

## 中国市场（ByteDance 重点）

- **ByteDance（Coze / Volcano / Doubao / Trae / Seed）**：已检查官方入口，未发现窗口内可核实的托管运行时、后台任务、远程环境、并发、企业控制面或定价新增。
- Alibaba、Tencent、Baidu、Zhipu、Moonshot/Kimi、MiniMax、DeepSeek 与可信创业公司：本轮无可核实新增。

## AaaS 与 MaaS / PaaS 边界

本轮两条重点都包含由服务方管理的执行生命周期及治理机制，因此归入 AaaS。仅提供模型推理端点、云主机或开发框架而没有托管 Agent 执行证据的候选不列为正式动态。

## 趋势

企业 AaaS 的竞争面正从“能否调用工具”进一步移向长周期恢复、记忆、权限继承、动作审计和人工升级机制。今天的两个案例分别从通用 CRM/业务流程平台和垂直文档基础设施印证这一方向。
