## AaaS vs MaaS / PaaS

- 只有服务方托管或管理 Agent 的执行、环境、生命周期、编排、观测或企业控制面时，才计为 AaaS。
- 仅提供模型推理与工具调用 API 属于 MaaS 邻近信号；没有托管 Agent 生命周期，不能因“Agent”字样直接纳入。
- 通用计算、沙箱、容器或 Workers 若只提供基础设施而不管理 Agent 生命周期，更接近 PaaS。
- 本地或自托管 coding harness 即使支持后台任务、subagent 或并发，也不能自动证明存在供应商托管服务。
