## 今日概览

本轮窗口为 **2026-11-16 10:42 至 2026-11-17 10:42（Asia/Shanghai）**。OpenAI 在医疗与科研垂直场景集中更新：医疗团队的 computer-use agents 发布了新的性能、安全与成本结果，ChatGPT for Healthcare 增强临床搜索并新增医疗插件；科研人员资助计划扩大。Codex、Responses API、Agents SDK 与 Realtime API 在官方渠道未发现窗口内的新版本公告。

## Tier 3：企业、医疗、科研与安全

- **医疗 computer-use agents**：OpenAI 发布面向医疗团队的 computer-use agents 新结果，覆盖临床与行政工作流的性能、安全和成本，并列出 Abridge、Ambience、Cigna Healthcare、CVS Health 等合作方。该页面强调 Agent 可在现有软件间点击、输入并完成多步流程。[官方原文](https://openai.com/index/advancing-computer-use-for-healthcare-teams/)
- **ChatGPT for Healthcare**：临床搜索获得改进，并新增 20 多个医疗插件；computer-use agents 用于在 EHR、政策、排程和保险门户之间推进工作。[官方原文](https://openai.com/index/more-ways-to-move-care-forward-with-chatgpt-for-healthcare/)
- **科研资助扩容**：ChatGPT for Academic Researchers 计划目标扩大到全球最多 20 万名研究人员，下一轮拟新增 5 万份资助，每份可覆盖申请者与最多两名协作者。[官方原文](https://openai.com/index/expanding-chatgpt-for-academic-researchers/)
- **企业采用**：LVMH 媒体部门与 OpenAI 签署战略合作，计划向旗下媒体团队部署 OpenAI 工具与 ChatGPT Enterprise。[官方原文](https://openai.com/index/lvmh-media-division-partnership/)
- **安全工具**：OpenAI 模型发布说明新增 CSAM 图像分类器，免费 API 访问需申请、验证与项目 onboarding；官方明确它用于辅助受训审核人员排序，不能替代人工判断。[官方说明](https://help.openai.com/en/articles/9624314-model-release-notes)

## 官方更新（由新到旧）

1. **ChatGPT for Healthcare 与医疗 Agent（11 月 16 日）**：这是本轮最明确的 Agent 产品信号，重点不在新基础模型，而在跨系统执行、临床证据搜索和插件生态。
2. **科研人员计划扩容（11 月 16 日）**：属于 Science / Edu 采用信号，强调数据默认不用于训练。
3. **LVMH 媒体部门合作（11 月 16 日）**：属于 Enterprise 采用信号。
4. **CSAM 图像分类器（11 月 16 日）**：属于受限安全 API，而非公众通用模型发布。

## Love

本轮没有发现可量化、可交叉核实的新增正面社区样本。官方发布与合作公告不计作正面口碑。

## Hate

- GitHub 用户提交了可复现报告，称其 macOS Codex / ChatGPT 桌面环境内置 Node 仍为 24.22.1，并复现与 2026 年 11 月 Node 安全公告相关的 TLS session cache-key 差异。报告明确没有证明端到端可利用性，且截至采集时属于**社区问题单、尚未获维护者确认**。[GitHub issue #61756](https://github.com/openai/codex/issues/61756)

## 口碑判断

**中性，置信度低。** 官方侧有明显医疗 Agent 与企业/科研采用进展，但公开社区样本不足；唯一保留的负面样本是具备复现实验的 GitHub issue，仍不能外推为普遍安全事件或完整产品口碑。

## 对比与 Agent 生态

本轮官方信息表明 OpenAI 正把 computer-use agents 推入受监管医疗工作流，竞争维度从模型能力转向跨系统执行、安全评测、插件与组织采购。窗口内未发现足以支持 Codex 与 Claude Code、Cursor、Cline、Pi Coding Agent 或 DeepSeek Harness / DSH 的性能优劣结论；完整 harness 更新留给开源专题页。
